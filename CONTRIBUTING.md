# Contributing

waypoint is a personal portfolio project, not a large open-source effort. There
is no process to speak of: open an issue if something is broken or missing, and
open a pull request if you want to fix it. Small, focused changes are the ones
most likely to be merged. Nothing is guaranteed to be merged at all.

Before you send a change, run `npm test` and `npm run typecheck`.

## Licensing

Contributions are accepted under the [MIT License](LICENSE), the same license
the project is released under.

By submitting a contribution you agree that the project owner may relicense the
project — including your contribution — under different terms. This keeps a
clean relicensing path open, which matters because the architecture
deliberately leaves an open-core model available. You keep the copyright in
what you wrote; this is permission, not a transfer.
